# RescueTwin AI - Project Overview

RescueTwin AI is a smart flood response dashboard for a fictional district.

It is not a real emergency system. It is a demo project that shows how AI can help people understand floods, choose safe routes, and make better emergency decisions.

## What the project does

- Simulates flood conditions for one fictional district
- Shows flooded zones and blocked roads on a map
- Predicts how severe a flood may become
- Checks a sample damage image and estimates damage level
- Finds a safe route for rescue movement
- Recommends the nearest suitable hospital
- Recommends the safest shelter
- Assigns the best rescue team based on the situation
- Explains why each recommendation was made
- Generates a short incident report

## Main idea

The user selects a flood scenario like moderate, severe, or extreme. The system then updates the map and shows which areas are affected. After that, it gives rescue recommendations based on safety, distance, and availability.

## Simple user flow

1. Open the dashboard.
2. Choose a flood scenario.
3. View the affected areas on the map.
4. Select an incident.
5. See the best route, hospital, shelter, and rescue team.
6. Read the explanation.
7. Generate the incident report.
